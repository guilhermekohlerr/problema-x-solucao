# Problema X Solução

Base de conhecimento visual para registrar, pesquisar e consultar problemas e soluções de suporte em lojas.

## Funcionalidades

- Catálogo de ocorrências por categoria
- Pesquisa sem distinção de acentos
- Filtros rápidos
- Tema claro e escuro
- Janela com detalhes completos
- Cadastro guiado de novos problemas
- Geração automática de palavras-chave
- Dados fictícios para demonstração

## Como executar

Baixe ou clone o projeto e abra `index.html` no navegador. Não é necessário instalar dependências.

## Arquivos

- `index.html`: interface e funcionamento do projeto
- `dados.js`: base fictícia de problemas e soluções

## Privacidade

O projeto acompanha apenas dados fictícios. Não inclua senhas, dados pessoais, credenciais ou informações sensíveis na base.
